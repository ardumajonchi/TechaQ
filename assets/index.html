Barcode scanner device exclusion

The barcode scanner is read by a host-side service (host/scanner_reader.py), outside this app's container, since raw USB/Bluetooth HID input devices aren't reachable from inside it. That service watches every keyboard-like input device by default, which can pick up a real attached keyboard by mistake.

To exclude a device, add a case-insensitive substring of its name to a plain JSON list at this path on the board's host OS (not inside this app's container): 

~/.config/techaq/excluded_devices.json

Example contents:

["Logitech", "My Keyboard"]

This file is only read once, at startup -- after editing it, restart the scanner service on the board: 

systemctl --user restart techaq-scanner.service

This page is informational only for now; there's no in-app editor for this file yet since it lives outside this app's container filesystem.

Import / Export library (CSV)

Export every book in the library as a CSV file, or import a CSV file of books (matching that same export's column headers). Rows whose ISBN already matches a book already in the library are skipped rather than duplicated.

About

TechaQ -- a home book-collection inventory manager for the Arduino UNO Q. Scans EAN/ISBN barcodes, fetches metadata from Open Library / Google Books, tracks shelf location, and supports natural-language and shelf-photo (OCR) search/entry.
